# hacker_HP 스펙 문서

동아리 구성원이 학습 자료를 공유하고 공지·활동사진을 확인하는 폐쇄형 커뮤니티 사이트다.

이 폴더는 **"무엇을 왜 이렇게 만드는가"** 를 기록한다. "어떻게 일하는가"(커밋·브랜치·PR)는 [`CONTRIBUTING.md`](../CONTRIBUTING.md)가 원본이고, 인프라·배포 실물 절차는 [`docs/`](../docs)에 있다. 여기서는 링크로만 연결한다.

## 문서 상태

| 항목 | 값 |
| --- | --- |
| 상태 | Baseline v1 |
| 기준일 | 2026-08-03 |
| 제품명 | hacker_HP |
| 저장소 | https://github.com/HackerKHU/hacker_HP |
| 기준 코드 | **없음** — 구현 착수 전이다 |

**이 프로젝트는 스펙을 먼저 확정하고 구현이 스펙을 따른다.** 코드가 아직 없으므로 이 문서의 거의 모든 내용은 "확정 스펙, 미구현"이다. 성격이 다른 절은 서두에 상태를 표기한다.

| 표기 | 뜻 | 구속력 |
| --- | --- | --- |
| (표기 없음) | **확정 스펙, 미구현** — 구현이 따라야 할 요구사항 | **있음. 구현 PR은 이 스펙으로 심사한다** |
| `상태: 현재 코드 반영 완료` | **사실 기록** — 구현된 것을 코드에서 확인해 적었다 | 있음. 코드를 바꾸면 문서도 바꾼다 |
| `상태: 미결정` | **미결정** — 선택지만 있고 결정되지 않았다 | **없음. 착수 전에 결정해야 한다** |

미결정 항목은 [1-BACKGROUND §1-5](1-BACKGROUND.md)에 모아둔다. 그 표가 비어야 Baseline v2다.

## 키워드

요구사항 문장은 다음 키워드로 강도를 구분한다.

- **MUST** — 반드시 지킨다. 어기면 리뷰에서 반려 대상이다.
- **SHOULD** — 권장한다. 어길 때는 PR 본문에 이유를 남긴다.
- **MAY** — 선택이다.

## 읽는 순서

```text
1     BACKGROUND               제품 정의, 범위, 용어, 기술 스택, 미결정 사항
2-1   USER-STORIES             부원이 무엇을 하려고 하는가 (자료·공지·사진·화면)
2-2   OPERATOR-REQUIREMENTS    관리자가 무엇을 유지해야 하는가 (회원 관리)
3-1   DESIGN-ARCHITECTURE      Role/Status, 권한 매트릭스, 인증 흐름  ← 권한 작업 전 필독
3-2   DESIGN-CONTRACT          테이블 정의와 API 명세
3-3   DESIGN-DECISIONS         결정 5건 + 비기능 제약
5     TESTING                  검증 기준, 테스트 사례, 오류 처리
7     DEPLOYMENT               배포 원칙 (실물 절차는 docs/ops/)
```

4번(고유 도메인), 6번(관측), 8번(데이터 출처·법적 사항) 레이어는 만들지 않는다. 텔레메트리를 두지 않고, 외부 데이터를 수집하지 않으며, 별도 도메인 레이어라 할 만한 것이 없다.

## 변경 원칙

1. **권한이 바뀌는 변경은 [3-1](3-1-DESIGN-ARCHITECTURE.md) 매트릭스를 같은 PR에서 갱신한다** (MUST). 매트릭스에 없는 조합이면 추측하지 말고 먼저 묻는다.
2. **스키마나 API가 바뀌면 [3-2](3-2-DESIGN-CONTRACT.md)를 같은 PR에서 갱신한다** (MUST). Flyway 마이그레이션이 이 정의를 그대로 반영해야 한다.
3. **결정을 뒤집을 때는 [3-3](3-3-DESIGN-DECISIONS.md)의 기존 항목을 고치지 않고 새 항목을 추가해 "N번을 대체함"이라고 적는다** (MUST). 히스토리가 남는 것이 이 문서의 존재 이유다.
4. 미결정 항목을 확정하면 [1-BACKGROUND §1-5](1-BACKGROUND.md)에서 내리고 해당 설계 문서에 반영한다 (MUST).
5. 구현이 끝난 절은 서두에 `상태: 현재 코드 반영 완료`를 붙인다 (SHOULD).
