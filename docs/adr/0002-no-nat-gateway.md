# 0002. NAT Gateway를 쓰지 않는다

- **상태**: 승인됨
- **날짜**: 2026-08-01

## 배경

프라이빗 서브넷(RDS)에서 인터넷으로 나가려면 보통 NAT Gateway가 필요하다. 하지만 NAT Gateway는 월 5~6만원으로, 이 프로젝트 전체 예산(월 3.5만원 목표)을 그것만으로 초과한다.

## 결정

NAT Gateway를 두지 않는다. ECS 태스크는 퍼블릭 서브넷에 `assign_public_ip = true`로 배치해 NAT 없이 ECR/SSM에 접근하고, 인바운드는 보안그룹(ALB SG만 허용)으로 막는다. RDS는 아웃바운드가 필요 없으므로 프라이빗 서브넷에 완전히 격리한다.

## 이유

NAT은 "프라이빗 서브넷에서 인터넷 나가는 배관"일 뿐 그 자체로 필수 보안 요소가 아니다. SG를 CIDR이 아닌 SG-참조로 제한하면 퍼블릭 서브넷에 있어도 외부에서 태스크로 직접 접근할 수 없다.

## 트레이드오프

태스크의 퍼블릭 IP가 노출된다(SG로 차단되지만 네트워크 경로 자체는 열려 있음). 부원 수·예산이 늘면 라우트 테이블 수정 수준으로 NAT을 다시 추가할 수 있다.
