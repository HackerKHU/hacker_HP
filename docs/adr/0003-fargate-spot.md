# 0003. ECS Fargate Spot을 쓴다

- **상태**: 승인됨
- **날짜**: 2026-08-01

## 배경

컨테이너 실행 환경으로 EC2 직접 관리, ECS Fargate(온디맨드), ECS Fargate Spot을 검토했다. 동아리 규모상 서버 관리 인력이 없고, dev 환경은 24/7 무중단이 필수는 아니다.

## 결정

ECS Fargate Spot을 기본 용량 공급자로 쓴다 (`FARGATE_SPOT`, weight 1). EC2를 직접 운영하지 않는다.

## 이유

Fargate는 서버 패치·스케일링을 직접 하지 않아도 된다. Spot은 온디맨드 대비 약 1/3 비용이며, 배포 서킷 브레이커와 ALB 헬스체크를 같이 쓰면 회수(reclaim) 시에도 대부분 무중단으로 넘어간다.

## 트레이드오프

AWS가 용량을 회수하면 태스크가 순간적으로 재시작되며 짧은 응답 끊김이 생길 수 있다. dev 환경에는 문제 없는 수준이지만, 프로덕션에서 엄격한 무중단이 필요해지면 온디맨드 weight를 섞어야 한다.
