# 0001. 모노레포로 구성한다

- **상태**: 승인됨
- **날짜**: 2026-08-01

## 배경

동아리 홈페이지는 백엔드(Spring Boot API), 프론트엔드(React), 인프라(Terraform)로 구성된다. 인원이 적고 저장소를 여러 개로 나눠 관리할 여력이 없다.

## 결정

`apps/api`, `apps/web`, `infra/terraform`을 GitHub Organization 안의 단일 저장소(모노레포)에 둔다.

## 이유

이슈·PR·문서를 한곳에서 추적할 수 있고, 프론트-백엔드 계약(API 명세, 타입)이 바뀔 때 한 PR로 같이 리뷰할 수 있다. 소규모 팀에서 멀티레포는 동기화 비용만 늘린다.

## 트레이드오프

CI 워크플로우에서 `paths` 필터를 신경 써야 한다 (`apps/api/**` 변경 시에만 배포 트리거 등). 팀/제품이 커지면 각 앱을 독립 배포 주기로 떼어낼 필요가 생길 수 있다.
