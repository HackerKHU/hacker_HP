# 구글 로그인 버튼 에셋

`signin-light-square.svg` — 구글이 배포하는 **공식 로그인 버튼**이다.

- 출처: `https://developers.google.com/static/identity/images/signin-assets.zip`
- 원본 경로: `Android + Web/SVG/Light/Theme=Light, Show text=Yes, Shape=Square, Platform=Android+Web.svg`
- 규격: 180×40, Light 테마, 텍스트 있음, Square

**이 파일을 고치지 않는다.** 색·비율·여백·글씨가 구글 브랜딩 가이드라인의 규정이고,
사전 승인된 형태 그대로여야 한다 (spec [3-1 §3-1-5](../../../../spec/3-1-DESIGN-ARCHITECTURE.md)).

**글씨를 한글로 바꿀 수 없다.** 글씨가 `<text>`가 아니라 **패스로 윤곽만 남아 있다** —
편집기로 열어도 문자가 아니라 도형이다. 한글 버튼이 필요하면 규격대로 다시 그려야 하고
`Google Sans Medium` 폰트가 필요하다. 그 경로는 검토했고 택하지 않았다.

파일 이름에 공백과 `=`가 있어 그대로 쓰지 않고 옮겨 적었다. 다시 받을 일이 있으면
위 원본 경로로 대조한다.
