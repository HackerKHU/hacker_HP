# 랜딩 정적 자산

랜딩(`/`)이 쓰는 이미지를 여기 둔다. 랜딩은 정적이라 API로 받아오지 않는다
(spec [3-3 결정 8](../../../../spec/3-3-DESIGN-DECISIONS.md)).

## 지금 들어 있는 것

| 파일 | 쓰이는 항목 | 크기 |
|---|---|---|
| `club.jpg` | 소모임 | 1200×900 |
| `education.jpg` | 신입생 교육 | 1200×900 |
| `opening.jpg` | 개강총회 | 1200×900 |
| `samak.jpg` | 사막 | **900×1200 (세로)** |
| `mt.jpg` | MT | 1200×900 |
| `festival.jpg` | 축제 부스 | 1200×901 |
| `closing.jpg` | 종강총회 | 1200×900 |

**아직 없는 것** — 신입생 멘토멘티 하나뿐이다. 화면에는 "사진 준비 중" 자리표시자가 그려진다.

`og-image.png`(1200×630)도 아직 없다. 없으면 카카오톡·인스타그램 링크 미리보기에 이미지가
비어 나온다.

## 규격

- 가로 1200px 기준. 카드는 **4:3 가로 상자**라 가로 사진이 잘리지 않는다.
- 세로 사진도 쓸 수 있지만 **위아래가 잘린다.** 얼굴이 잘리면 `content.ts`의 해당 항목에
  `crop`(Tailwind `object-*` 유틸리티)을 줘서 기준점을 옮긴다. `samak.jpg`가 그 예다.
- 원본 카톡 사진은 EXIF 방향이 틀어져 있을 수 있다. 넣기 전에 방향을 정규화한다.

## 연결 방법

1. 파일을 이 폴더에 넣는다.
2. `src/features/landing/content.ts`의 `ACTIVITIES`에서 해당 항목의 `src`를
   `/landing/<파일명>`으로, `alt`를 **사진 내용 설명**으로 채운다. `alt`는 장식이 아니라
   내용이므로 무엇이 찍혔는지 적는다.

`src`가 빈 문자열이면 "사진 준비 중" 자리표시자가 그려진다. 실물이 없다는 것이 드러나야
채워 넣을 생각을 하므로 의도한 동작이다.

**공개 페이지에 올라가는 사진이다.** 부원 얼굴이 크게 나오는 사진은 당사자 동의를 받고
올린다.
