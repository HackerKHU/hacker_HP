# 랜딩 정적 자산

랜딩(`/`)이 쓰는 이미지를 여기 둔다. 랜딩은 정적이라 API로 받아오지 않는다
(spec [3-3 결정 8](../../../../spec/3-3-DESIGN-DECISIONS.md)).

## 넣어야 하는 것

| 파일 | 쓰이는 곳 | 권장 규격 |
|---|---|---|
| `og-image.png` | `index.html`의 `og:image` — 카카오톡·인스타그램 링크 미리보기 | 1200×630 |
| 활동 사진 (파일명 자유) | 랜딩 "활동" 섹션 | 세로형(3:4), 가로 1200px 이하 |

## 활동 사진 연결 방법

1. 파일을 이 폴더에 넣는다. 예: `photos-2026-seminar.jpg`
2. `src/features/landing/content.ts`의 `PHOTOS` 배열에서 해당 항목의 `src`를
   `/landing/photos-2026-seminar.jpg`로, `alt`를 사진 설명으로 채운다.

`src`가 빈 문자열이면 화면에 "사진 없음" 자리표시자가 그려진다. 실물이 없다는 것이
드러나야 채워 넣을 생각을 하므로 의도한 동작이다.

**공개 페이지에 올라가는 사진이다.** 부원 얼굴이 크게 나오는 사진은 당사자 동의를
받고 올린다.
