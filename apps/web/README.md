# hacker_HP Web

React 19, TypeScript, Vite로 만든 프론트엔드 애플리케이션이다. 현재 보일러플레이트는 기능이나 API 호출 없이 최소 시작 화면만 제공한다.

## 요구 환경

- Node.js 24.15 이상
- npm 11 이상

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run lint
npm test
npm run build
```

기능 구현 전에는 [`AGENTS.md`](AGENTS.md)와 연결된 상위 스펙·컨벤션 문서를 확인한다.
