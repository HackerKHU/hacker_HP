# Web 작업 안내

이 파일은 `apps/web`에서 작업하는 Claude가 상위 프로젝트 지침과 Web 전용 지침을 빠뜨리지 않도록 연결하는 진입점이다.

작업이나 리뷰를 시작하기 전에 다음 문서를 순서대로 확인한다.

1. [`../../AGENTS.md`](../../AGENTS.md) — 저장소 공통 작업 및 코드 리뷰 규칙
2. [`../../CLAUDE.md`](../../CLAUDE.md) — 프로젝트 구조, 기술 스택, 공통 개발 규칙
3. [`AGENTS.md`](AGENTS.md) — Web 범위, 관련 스펙, 구현 규칙, 검증 명령

구현 세부사항은 이 파일에 중복해서 적지 않고 위 문서를 따른다. 요구사항, API 연동 또는 배포 방식이 바뀌면 연결된 스펙과 운영 문서도 같은 PR에서 갱신한다.
